# 调研方法与案例地图

采集日期按每个案例分别记录，数量与分类以自动生成的 [案例索引](CASE-INDEX.md) 为准。内容包含原站局部复现、官方视觉资料的网页转译和经典构成练习；三种范围在案例说明与复现边界中分别标注。

## 证据链

真实官网/原作者 → 浏览器视觉与滚动观察 → 元素、信息结构和交互记录 → 原素材本地归档 → 局部实现 → 桌面/手机操作与实际截图。来源无法打开时公开限制，不把搜索摘要冒充整页实访。

每项研究区分事实与推断。“大字、色块、网格”是观察；“它们如何突出产品重点”是分析，除非有作者叙述才标为作者意图。艺术案例也要分析展品、日期、预约、节目等内容关系，而不是泛用艺术装饰。

## 按地区研究的方法

地区筛选是检索入口，不是本质化审美判断。同在日本，21_21 的设计展示、森美术馆的机构信息、Fuji Rock 的年度活动宣传以及游戏页面承担不同任务，其字体、密度、素材和交互可以非常不同。应先对照具体机构与版本，再寻找可复用机制。

跨地区比较用相同问题：文字与图像谁先出现？标题尺度与行长怎样设定？网格是否稳定？主色用于背景、品牌还是行动？预约/下载和内容怎样靠近？滚动是章节递进、连续舞台还是信息列表？声音从何处启用、能否关闭？

文化案例覆盖中国的宫殿建筑、石窟壁画与江南博物馆，以及日本、荷兰、美国、法国的展览、博物馆、音乐节与音乐会/音乐展。游戏提供中国、日本、韩国和英国的创作来源，以及地区发行版本。不要从少量样本推断“某国设计都如此”。

详细样本比较见 [国别案例比较](COUNTRY-COMPARISON.md)，包括日本六例的视觉与交互差异。

中国文化方向可对照 [故宫](palace-museum.md) 的建筑章节与文化入口、[数字敦煌](digital-dunhuang.md) 的图像档案和分面检索、[苏州博物馆](suzhou-museum.md) 的建筑身份与目的地目录。“古风”在这些样本中分别来自建筑部件、文物与壁画、地方空间的具体表达，不仅是配色或毛笔字。

工业科幻方向分别看 [明日方舟](arknights-world.md) 的暗灰战术档案、[终末地](endfield-industrial.md) 的白底黄信号与技术模块、[莱茵生命](rhine-lab.md) 的官方影像档案构成。莱茵条目的网页选择／返回是教学改编，不能当作源官网行为；白底亮黄工业界面与莱茵机构视觉也不能互换名称。

## 设计选择与约束

- 硬件：真实产品摄影、尺度与细节负责证明，不用抽象球体代替产品。
- 平台：真实软件界面、工作结果与任务流程负责解释能力。
- 游戏/IP：世界、角色、玩法与章节节奏负责建立期待。
- 艺术/文化：作品/表演本身、策展主题和参观行动形成层级；日期与地点需要可查。
- 经典方向：网格、投影、线条、形色、像素和质感是构成原则；不同项目不必共享同一布局。

实验室把设计元素做成交互控件，用来观察变量怎样协调；品牌页则保留自己的结构。设计基础来源见 [foundations.md](foundations.md)。

背景媒体默认静音，有声必须显式启用。减少动效时全部内容可读；保留原生滚动。参考 [W3C Animation from Interactions](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)；本库借用相关约束，未声明正式认证。
