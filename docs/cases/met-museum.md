# The Met · 编辑式展览与馆藏陈列

## 真实来源与理论

- [The Met official English homepage](https://www.metmuseum.org/en)（实例）：2026-10-07采集英语首页：建筑静图、白底欢迎区、参观信息与原生展览横架。
- [The Met Image and Data Resources](https://www.metmuseum.org/policies/image-resources)（规范）：Open Access区分公众领域与受限制作品；本地OA藏品采用各自的许可记录；海报、字体、品牌及首页影像的权利记录见素材清单。
- [W3C WAI Disclosure Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/)（规范）：内容显隐按钮与状态语义的实现参考。

## 构成与设计逻辑

官方建筑摄影开场，Austin衬线欢迎区与四列参观信息接续；展览海报和馆藏以原生横架展开。

| 元素 | 职责与约束 |
|---|---|
| 配色 | 白底黑灰字和红色操作层，图像保持展览自己的颜色。 |
| 字体 | Austin衬线大标题与Inter目录型小文本产生编辑层级。 |
| 版式 | 宽幅建筑摄影约725px高；欢迎区左右分工，横架保持白底、图下题注。 |
| 图像 | 官方建筑摄影、Sanity CDN展览海报与符合条件的Met API藏品图，本地保留比例、署名与原色。 |
| 形状 | 方角海报与细边CTA，会员区域仅一个轻边框圆角区域。 |
| 层级 | 建筑图像呈现实体空间，欢迎区提供行动，四列信息减轻到访决策，展览海报与馆藏引导浏览。 |
| 动态 | 原生连续阅读与水平展览轨道，导航即时展开；本地详情／搜索dialog有明确范围。无背景音乐或强制章节转场。 |
| 协调 | 字形分工、Met红操作与白底图下文字一致，馆藏照片与海报使用不同图像比例。 |

## 交互巧思

| 触发 | 采集页面响应 | 设计作用与范围 |
|---|---|---|
| 进入首页 | 建筑静图与品牌立即进入，无额外加载欢迎层。 | 先定位机构与实体空间，随后欢迎区突出到访行动。 |
| 上下浏览 | 原生长页，欢迎信息、展览、馆藏与会员依次展开。 | 保持编辑式阅读节奏，不加入原站没有的全屏遮罩。 |
| 横向浏览展览 | 原生溢出，scroll-snap:none，按钮与触摸可操作。 | 并列比较展览，方向反馈清楚。 |
| 打开Visit等导航 | 目的地即时展开。 | 到访任务直接可达；局部搜索／作品dialog是本地练习补充。 |
