## 文章主题与样文

从 [Reacticle 的主题样文](reacticle.md#11-套主题样文) 比较相同组件体系中的排版语言，再读取快照的 `theme-profiles/`。其中 11 份主题 Markdown 与索引用于指导写作；样文的组件与 CSS 由 Reacticle 提供。

需要创建工程时，按技能原文使用脚手架，把占位标题、正文与封面替换为源材料。脚手架生成 React、TypeScript 和 Vite 工程并安装 reacticle；文章的字体与离线资源按实际交付目标配置。
