# Web Design Engineer · 网页设计工作流

## 它解决什么问题

Web Design Engineer 为 Agent 提供制作网页作品的方法：先理解受众、事实和参考，再把设计方向落实到配色、字体、网格、素材、组件与交互。它适用于从零创作，也区分既有界面延展、保留式重设计与完整重设计，避免在实现中无意改变需要保留的业务和交互。

本库收录的是 [garden-skills 固定提交中的技能](https://github.com/ConardLi/garden-skills/tree/2b9a89340b70f632d31c0f1c69fce94a7912423e/skills/web-design-engineer)，版本声明为 1.3.0。条目展示工作流和关联作品，完整原文保存在本地快照中。

## 工作流

1. 核实产品、品牌与技术事实，明确受众、作品类型和约束。
2. 优先读取用户提供的代码、素材与参考；涉及已有界面时，先确定延展、保留式重设计或完整重设计的范围。
3. 梳理设计判断，校准视觉变化、动效强度、信息密度、素材依赖与品牌忠实度；确定叙事角色、观看距离、视觉温度和内容容量。
4. 声明配色、字体、间距、圆角、阴影及运动规则，请用户确认设计系统。
5. 展示可浏览的首版结构和关键模块，请用户确认方向，再完成组件、状态与动效。
6. 执行代码与设计自查；用户明确要求浏览器验收、响应式检查或同类实测时，再运行相应验收流程。按设计理念、视觉层级、工艺、功能和独创性评议并修复问题。

快照中的 25 份具名风格配方按需阅读，每份提供具体设计规则。固定提交没有 README 所指配方画廊的页面源码。

## 适合与不适合的场景

适合制作网页、交互原型、数据可视化和设计系统探索，也适合在已有界面中增加模块或做保留式重设计。需要以明确参考校准风格，或对网页作品进行设计评议时，可以使用这套工作流。

不适合后端接口、命令行和纯逻辑开发。将材料转成完整长文属于 Beautiful Article 的工作范围；按旁白节拍组织视频演示也不是本技能的目标。
