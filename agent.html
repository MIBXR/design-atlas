01 / SKILL

先探索，再围绕需求选方向

skill 提供选型工作流与获取脚本，完整案例留在 Design Atlas。新任务读取最新目录，讨论和取材使用同一版本。你可以从“有哪些案例”开始。

查看 skill 与获取脚本 ↗

安装 skill 后，可以这样开始

$design-atlas 我还没决定网站的设计方向，先介绍有哪些案例。
接下来根据我的产品、用户和页面任务，和我一起筛选几个候选。
确定方向后，自动读取完整说明、文档和源码，再完成实现。

02 / RETRIEVE

探索案例，也可以直接取材

结构化索引 JSON ↗

搜索品牌、布局、场景或交互关键词。“案例包”是一个 JSON：包含完整设计资料、网页右侧说明、文档原文，以及源码和媒体的路径与校验信息。已经选好案例时，可以直接复制入口。

03 / LOCAL WORKFLOW

仓库里也能直接运行

Node.js 即可使用，无需安装依赖。完整导出保留 Demo、共用模块、字体和媒体的相对路径；大型品牌案例可能包含影片。

读取完整工作流与数据契约 ↗
node scripts/atlas.mjs search "深色 产品" --limit 3
node scripts/atlas.mjs show linear-workflow
node scripts/atlas.mjs show linear-workflow --source
node scripts/atlas.mjs export linear-workflow --out ../linear-reference

DESIGN WITH CONTEXT

带着依据适配你的场景

保留设计机制
读取布局、视觉层级、状态和触发关系，选择能解释当前产品的表达。

替换真实内容
用自己的品牌、文案和有使用权的素材，依据真实功能调整交互。

验证当前成果
检查桌面与手机、键盘、减少动态和资源加载，保留来源中近似与未验证的标记。
