# 80年代：合成器面板

调研日期：2026-10-07。本条聚焦模拟合成器设备的复古方向，不能代表80年代的全部平面设计、孟菲斯设计或大众文化。

## 真实案例与规范

[Arturia Jup-8 V 官方产品页](https://www.arturia.com/products/software-instruments/jup-8-v/overview) 以复古乐器的声音、直接控制、预设和现代增强功能解释产品；该页说明原始 Jupiter-8 在1981年推出。其产品价值是可以演奏和调整的音色，不只是设备的外观。

[Arturia 官方2014年手册](https://downloads.arturia.com/products/jupiter8-v/manual/Jupiter-8V_Manual_2_6_0_EN.pdf) 第59页（PDF索引58）分出原始面板、预设管理、扩展控制、效果四部分，并说明振荡器、滤波器、放大器和包络模块。这是本例信息分区的依据。手册版本是历史证据，不能用它推断当前软件每一个按钮的位置。

[MDN Web Audio API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API) 提供浏览器音频节点的实现模型。本 demo 通过 OscillatorNode → BiquadFilterNode → GainNode 构建简化链路，采用用户主动开启声音的方式。

## 我的设计判断

设备面板的价值是把功能关系变为可看见的空间关系。用户的路径应是“找到一个声音 → 理解关键参数 → 演奏 → 知道可继续调整什么”。因此 Nightshift 的首屏不是一个普通营销卡片墙，而是可操作的仪器。橙色分区和米白标签建立年代感；青色波形和读数提供状态，色彩亮度受控，不用霓虹遮盖文字。

这是一种“历史设备的现代网页迁移”，不是声学复刻。demo 使用一个振荡器，三预设是原创参数组合，不标示为原设备工厂音色。

## 复现映射

| 来源启发 | 本地实现 | 核心检查 |
|---|---|---|
| 直接可调面板 | 预设、Cutoff/Attack/Output滑块 | 修改读数确实修改音频参数 |
| 原始/预设/扩展分区 | 面板三分区和后续信号链 | 功能标签可读 |
| 演奏产品展示 | 白键与黑键按钮 | 点击/键盘能发声且能停止 |
| 现代易用性 | 默认静音、明确电源按钮 | 用户操作前无音频 |

## 约束

面板不可出现没有功能的“假旋钮”。使用原生范围控件，所有数字显示具体单位。屏幕键都有可读音名；物理键演奏只在声音开启后生效，滑块获得焦点时保留正常键盘操作。切出页面、关闭声音或离开页面时停止当前音符。手机上先预设，再显示与参数，最后琴键；不把密集标签压到不可读。没有外部音频、字体或CDN。
