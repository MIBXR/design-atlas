## 构成与设计分析

**可观察事实：**参考Cygames国际英文宣传页，而非日本门户。桌面是满宽赛道群像，手机有独立竖版KV；平台徽章稳定在画面边缘，新闻使用白底日期条目。About预告倾斜居中，Gameplay将大立绘、两幅竖屏截图和斜切说明放进同一面板。

**本库分析：**群像的纵深与荧绿斜切条带共同形成前进感，真实竖屏画面解释训练、学园和比赛。新闻的白底降低密度，下载徽章保持标准轮廓，使运动主题不破坏操作辨识。

| 维度 | 设计职责与约束 |
|---|---|
| 配色 | 草地绿来自官方赛道KV；#c0e640斜切标题带与绿色操作入口重复，白底新闻让复杂图像后出现阅读休息。 |
| 字体 | 官方图内标识保留；本地段落使用粗重斜体无衬线标题、普通正文和小号日期，避免所有内容同等抢眼。 |
| 版式 | 主视觉整幅铺开，新闻以横向条目排列，预告居中，玩法以截图与立绘叠合；不套统一hero卡片模板。 |
| 素材 | 原站公开KV、三名角色立绘、六张游戏截图与预告缩略图本地保存；每项有manifest来源。 |
| 形状 | 向前倾斜的标题带、说明板与箭头复用斜切语言，平台下载徽章保持自己的标准轮廓。 |
| 层级 | 赛道群像先建立游戏辨识；下载次之；新闻较安静；Gameplay每态只突出一个玩法及相关人物。 |
| 动态 | 三组完整玩法面板400ms cubic-bezier(.25,1,.5,1)水平移动，原站时序与边界被保留；首尾停止、无自动推进，减少动态即时切换。 |
| 整体关系 | 斜切条带延续赛道纵深与角色奔跑方向；游戏截图提供玩法证据，群像负责情绪，二者各有职责。 |

## 复用约束

- 该页选择国际英文版 https://umamusume.com/；不能把日本门户与国际宣传页当作同一布局。
- 本地官方角色、背景和截图仅作私人学习，权利仍归 Cygames；公开再发布需自行取得授权。
- 复杂主视觉旁的文字与按钮必须落在稳定位置，不能压在角色脸部。
- 三态轮播不自动翻页，保持文本、图像与当前状态同步且可键盘操作。
- 没有获得原站 BGM，不提供假音频开关；预告是用户主动打开的官方外链。
- 手机使用原站单独的竖版 KV，并重新安排徽章；reduced-motion 取消非必要过渡与平滑滚动。

规范来源用于本地交互约束；除明确标注的第一方自述外，设计理念解释均为本库对选定样本的分析，不冒充品牌作者声明或整站合规结论。
