## 构成与设计分析

**可观察事实：**中国大陆官网以黑灰网格、青色编号和裁切RHODES ISLAND字建立工业系统。OPERATOR区彩色人物与放大灰度人物叠合，档案左置、索引右置；当前官网阿米娅可显示E0，分块进入的delay为0/200/400/600/800/1000ms。WORLD以六个术语连接世界观。

**本库分析：**编号与档案把玩法包装成罗德岛资料系统，彩色干员在灰度背景上保持情感焦点。青色主要承担状态与行动，而不是给每块内容加相同装饰；世界观术语提供阅读深度。

| 维度 | 设计职责与约束 |
|---|---|
| 配色 | 黑灰冷静工业档案，青色状态、细网格、罗德岛符号与超大裁切字；角色彩色图提供情感与焦点。 |
| 字体 | 大号Arial Black式英文字 + 明确中文档案；小英文索引用系统无衬线 |
| 版式 | 满屏PV+裁切字首页；左档案/右巨立绘；固定右索引；世界术语目录 |
| 素材 | 官方PV04静音视频、3人两精英阶段立绘、肖像与罗德岛标识。 |
| 形状 | 工业网格、细线目录、方形肖像、青色索引与CSS源石晶体局部替代。 |
| 层级 | 品牌舞台与下载 → 干员/阶段/声音档案 → 世界术语。 |
| 动态 | 干员和档案纵向分块进入，每块200ms错开有官网依据；本地500ms与cubic-bezier(.22,1,.36,1)为近似。PV、BGM和两位干员语音可停止。 |
| 整体关系 | 网格、裁切字、索引和档案都表达同一工业系统；灰度背景托住彩色人物，青色只表示操作状态。 |

## 动态机制与本地映射

| 区域 | 原站依据 | 最终本地实现与差异 |
|---|---|---|
| 干员演出 | 人物与资料沿纵向进入，分块delay每200ms错开。 | 三位凯尔希/阿米娅/陈的真实E1/E2立绘；切角色或阶段重播纵向进入。每块500ms、cubic-bezier(.22,1,.36,1)为本地近似，200ms间隔有原站依据。 |
| 首屏PV | 官网PV04影像作为品牌舞台。 | 约18.13秒1440×810静音PV，播放由首页可见性独立控制；可暂停，后台和减少动态停止。 |
| BGM与语音 | 公开BGM与干员语音是不同媒体。 | 约195.65秒官方BGM默认关闭，未取得曲名。阿米娅/陈可主动播放官方日语语音，切干员停止旧语音；凯尔希按钮明确不可用。 |
| 世界效果 | 官网有WebGL世界视觉与六个术语。 | 六项简短摘要可切换，CSS源石为局部替代，不称作官方WebGL。 |

原站六位干员，本地只含三位；没有E0、全部配音、完整档案或WebGL场景。减少动态取消进入动画而保留角色、精英阶段和术语操作；媒体播放失败时显示状态反馈。

## 复用约束

- 官方素材只作本地私人学习，版权归鹰角网络。
- 本地保留3名干员，原站有6名；语音覆盖阿米娅/陈，凯尔希语音按钮明确不可用。
- 剧情介绍使用简短学习摘要，完整文本回原站。
- 本地CSS源石替代原站WebGL粒子，并明确局部差异。
- BGM与角色语音不是同一类型，不混淆曲名或配音。
- 手机重新排档案和人物，固定索引不能挡住主操作。

规范来源用于本地交互约束；除明确标注的第一方自述外，设计理念解释均为本库对选定样本的分析，不冒充品牌作者声明或整站合规结论。
