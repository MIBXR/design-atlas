# 明日方舟 · 全屏档案与交互点阵

唯一来源：[中国大陆简体中文明日方舟官网](https://ak.hypergryph.com/)。采集日期 **2026-10-07**。这是本次当下页面的归档快照；下述原站事实来自全新入口、重新载入、六章节正反遍历、WORLD 指针与词条操作、390×844 竖屏以及公开 CSS/JavaScript。设计目的为本库分析，不冒称品牌作者自述。

## 交互巧思

| 触发 | 可观察响应 | 可复用的设计目的 |
|---|---|---|
| 首次进入 | 满屏灰色字标与 LOADING 计数先占据视野，载入完成后才打开首页。 | 把真实资源等待纳入品牌叙事，让重媒体首屏有明确入口。 |
| 向下切章 / 向上返回 | 下一章从右边/左边水平揭入；旧章与新章的裁切边界相接，右侧编号和名称同步在小窗口里滚动。 | 用方向与位置同时解释章节转换；始终保持一屏一个完整舞台，避免电影构图被普通文档滚动截断。 |
| WORLD 内移动指针 | 组成罗德岛标识的白色点在指针周围分开，移开后重新聚集；悬停术语显示带弯曲与色彩偏移的随动原图。 | 让“世界资料”具有材料反馈，鼠标成为探索工具；反馈来自内容形状而非通用光标装饰。 |
| 点击术语 | 点阵变成真实词条模型，目录转为说明与分段导航；竖屏直接呈现第一词条详情。 | 同一数据舞台同时承担浏览和阅读，手机减少一次进入目录的操作。 |
| 选择干员 / 阶段 | 原始角色图保持焦点裁切，档案按 200ms 间隔分块进入，配音有独立触发。 | 将人物、文字与声音绑到同一选择，建立角色而非模板式卡片。 |
| 音乐开关 | 官方音轨 600ms 线性渐入、300ms 渐出后暂停，章节切换延续同一背景声。 | 声音支撑开场与连续章节的氛围，音量变化缓和操作反馈。未确认原站专用点击或章节音效，不能把 BGM 当作操作音。 |

## 视觉系统如何支撑机制

黑灰网格与原始织物纹理给资料舞台统一坐标；青色只集中表达当前编号、进度、选中状态与行动。Bender 提供工业状态文字，Oswald 和 Novecento 提供压缩/宽体的标题对比。固定暗色承托彩色立绘和白色粒子，首页 PV 与场景内容无需切换主题；本次官网未观察到深浅色控制。

源站 SectionItem 在固定 100vw 内容外改变水平宽度；横屏转换 1000ms、竖屏 600ms，方向对应左右锚点。Indicator 的三组窗口采用 300ms 出/入和 100ms 错开。WORLD 采用 10,000 点池；罗德岛标识 1785 点，六项模型依次为 3550、4230、3882、4788、3200、5652 点。指针力按距离平方衰减，点同时向目标回归；这解释了移入时的局部空洞与移开后的复原，不能替换成静态晶体或整块缩放。

## 最终本地范围

六章与页脚都由同一状态控制器衔接；正反蒙版、编号时间线、真实几何、原始图像 shader、词条阅读和三个角色的 E1/E2/日语配音均可操作。Three.js 仅从公开包隔离渲染模块，点阵模型保持原始数据；页面没有引入官网账户或遥测模块。本地 clip-path 模拟源站宽度裁切，曲线为 easeInOutQuad 的 CSS 近似；编号结束时统一归位，首次加载的最短展示时间为本地媒体预算。

INFORMATION 内容缩为一张活动图与三条新闻；MEDIA 用四类图像链接网格近似原站桌面物件构图；MORE 保留四个外部入口和移动图像，页脚托起高度为本地 260px。省略完整新闻分页、六人/E0、全部语种、深层媒体浏览和独立 20 点背景萤火。首屏视频保留约 18.13 秒静音片段，BGM 使用完整独立官方音轨。

本地声音默认关闭，点击后按官网 600/300ms 音量曲线开关；角色语音与 BGM 分离，动态暂停和减少动态不代替静音。页面失去前台时暂停音频与动态，音频返回不自动续播。减少动态保留相同静态点阵及完整导航；键盘和 50px 竖向手势触发章节控制器，横向手势让给浏览器，内层可滚内容先消费输入。
