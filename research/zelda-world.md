## 构成与设计分析

**可观察事实：**Nintendo 日本《王国之泪》WORLD 页以同一满屏视频舞台展示「翔ける／創る／紡ぐ」，日文主题在右，字标在左下，缩略目录在底部。声音 ON/OFF 入口与古代青绿图形先建立世界情境。章节改变时视频、标题与选中目录联动；公开脚本中的桌面 wheel 翻章逻辑被注释，不能据此把它解读为三段纵向长页。

**本库分析：**实景先呈现可做的动作，再让短动词给动作命名；稳定的边缘控件把中央空间交给游戏世界。青绿、细线和象牙色共同呼应古代技术的主题，这是对选定页面的分析。

| 维度 | 设计职责与约束 |
|---|---|
| 配色 | 天空蓝、古代青绿、象牙色标题；自然、神秘与开放探索。 |
| 字体 | 官方日文标题图片 + 小字号衬线副文；控件用系统无衬线 |
| 版式 | 同一满屏舞台内叠放三章视频；右侧主题，左下Logo，底缘缩略目录 |
| 素材 | 官方 HLS 每章前6段、本地转封装 MP4、官方字标与缩略图。 |
| 形状 | 细线、细边框与低干扰矩形目录，避免遮盖景色。 |
| 层级 | 场景 → 三个玩法动词 → 章节选择 → 真实官方入口。 |
| 动态 | 同一100svh舞台的三章视频联动切换；本地300ms线性亮度/淡化及标题位移近似，短片结束推进；暂停或减少动态时不自动推进。 |
| 整体关系 | 游戏实景、动作主题、细线目录与原站配乐共同让体验围绕探索，而不是抽象功能卡。 |

## 动态机制与本地映射

| 区域 | 原站依据 | 最终本地实现与差异 |
|---|---|---|
| 世界章节 | 缩略点击切换同屏章节，完整 HLS 在片尾前约1秒推进；脚本有300ms锁定。 | 一个100svh舞台叠放三段视频；仅当前段播放。短片 ended 推进下一章，暂停时停止推进；标题/亮度300ms为本地近似。 |
| 界面与输入 | 指针静止3秒后界面隐藏；没有有效的桌面滚轮逐章行为。 | 目录保持可见，提供按钮、左右键和水平触摸；不实现3秒隐藏和绿环加载。 |
| 声音与媒体 | 官网公开 BGM，未取得公开曲名。 | 保留约99.44秒原 BGM，默认关闭、用户点击播放；后台暂停。每章取前6个 HLS 分片转封装为无音轨 MP4，长度与原站不同。 |

本地没有完整 HLS、原站片尾前1秒策略、加载演出、Nintendo账号菜单及其他栏目。方向键、触摸和持续暂停是本地可用性补充；不能把300ms本地曲线称作官方完整演出。

## 复用约束

- 官方资源只用于本库私人学习，原素材权利归 Nintendo。
- 本地同屏三章为局部复现，过渡曲线与短片长度不同于完整官网。
- 短片采用每章前6段，并未宣称复现完整视频。
- 字幕与控制保持高对比，不用持续动效阻碍阅读。
- 背景视频必须有持续暂停机制，音频默认关闭。

规范来源用于本地交互约束；除明确标注的第一方自述外，设计理念解释均为本库对选定样本的分析，不冒充品牌作者声明或整站合规结论。
