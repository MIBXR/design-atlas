# 05 — 世界观与章节式探索

核验日期：2026-10-07。案例：任天堂《塞尔达传说：王国之泪》日本官网 WORLD 页。

## 实际观察

[WORLD 官网](https://www.nintendo.com/jp/zelda/totk/world/index.html)进入时提供声音 ON / OFF；选择 OFF 后能浏览满屏游戏画面。右侧标题覆盖画面，背景直接演示从天空进入世界。可访问树中三个章节为「翔ける / 創る / 紡ぐ」，导航区分 WORLD、CHARACTER、MOVIE。证据见 [本地画面](screenshots/zelda-world-source.jpg)。美国旧域名本次浏览器出现证书错误，未绕过，改用可正常访问的日本官方地址。

## 理论依据及推断边界

[任天堂开发者访谈 Part 1](https://www.nintendo.com/us/whatsnew/ask-the-developer-vol-9-the-legend-of-zelda-tears-of-the-kingdom-part-1/)说明续作沿用已有世界，以新的探索方式产生新发现。这里据此迁移的原则是：宣传页先呈现可探索的世界，再解释玩法。访谈讨论游戏设计，不是官网设计团队的意图声明。

章节式信息结构让读者依次理解「世界 → 探索方式 → 下一步」。这是对官网的设计分析，而不是作者公布的网页理论。[W3C 2.3.3 动效规范](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)提示滚动附加位移和视差需要可关闭；[APG Tabs](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)为互斥章节切换提供键盘与语义参考。

## Demo 映射

- 原创场景设计习作 **ISLAND STUDY / 群岛之间**，不使用林克、海拉鲁、官方纹章或游戏素材。
- 原创 SVG 的远山、云层、浮岛、瀑布建立前后空间；大标题与场景共享首屏。
- 世界按钮切换「天空、森林、遗迹」，同一画面明确改变环境色和地标显示；旁侧文字同步说明选择。
- 后续为世界地图/探索机制/出发入口，保留自然页面滚动，章节目录可以跳转。
- 不自动播放音频或视频。SVG 场景是静态插画及用户触发的轻微过渡，不等同于官网的实际游戏视频。

## 约束

需要优质世界素材才能成立；正文使用稳定深色背景，装饰层不截获指针。景色不能遮盖行动按钮。手机端内容按自然文档顺序排列。用户请求减少动态效果时取消过渡。游戏 IP 页面也要提供实际玩法线索，不能只有视觉氛围。
