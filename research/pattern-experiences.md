# 巧思的体验类型与可操作示意

巧思以可独立借用的机制为边界。完整案例保留布局、素材与交互如何协作，巧思库帮助判断其中哪一部分适合当前任务；没有独立机制的案例无需提取，也无需凑齐视觉、动效和声音。

## 两个检索维度

`experienceTypes` 回答“用户怎样感知或操作这个机制”，`category` 回答“机制承担什么用途”。例如，单开内容既有局部展开反馈，也有控制信息密度的职责，可标为微动效与信息状态；用途仍是内容组织。已有用途类别保留，不用一种分类替代另一种。

| 体验类型 | 边界 | 适配时关注 |
| --- | --- | --- |
| 视觉构成 `visual` | 静态即可识别的配色、字体、形状、图像与空间关系。 | 重点、比例、对齐与阅读层级。 |
| 微动效 `micro-motion` | 局部控件反馈，或辅助主体信息的装饰、提示与进出。 | 触发、回程、焦点、触控与减少动态。 |
| 主体与页面动效 `page-motion` | 整页开场、章节转场、滚动叙事，或承担主要信息的展示舞台。 | 内容交接、方向、时序、反向与快速输入。 |
| 声音与音效 `sound` | 音乐、操作音、人物语音、主动媒体声音及其启停与衔接。 | 主动启用、静音、重复、后台和声音归属；站外入口保留站外边界。 |
| 信息与状态 `structure` | 内容组织、导航、条件筛选、状态协调等机制。 | 用户是否知道当前范围、位置、选择与返回路径。 |

类型依据每项实际机制判断。画面尺寸不是微动效与页面动效的唯一分界：背景光点可以辅助阅读，主要媒体窗口的交接可以承担主体叙事。响应点击也不自动成为动效；即时更新条件、收藏或正文仍可以是信息与状态。确有不同职责时可多类型，不从案例整体风格或声音标签自动补齐。

## 共享本地示意的取材依据

[共享示意源码](../pattern-playground.js)在首页、巧思库和实验室使用同一组控制与状态；[独立入口](../demos/pattern-playground/index.html)集中展示五种机制。它用少量内容解释设计作用，完整来源、参数与证据继续由巧思包和来源案例提供。

| 示意 | 取材巧思 | 保留的机制与适配边界 |
| --- | --- | --- |
| 视觉强调 | [单一信号色集中强调](../patterns/restrained-signal-color.json) | 用强调色区分阅读重点；下划线与可调圆角是本地补充。 |
| 局部反馈 | [按压与聚焦改变容器形状](../patterns/state-shape-feedback.json) | 形状与状态共同反馈；本地浮起、圆角和时长用于比较，未沿用来源 CTA 或资源卡的具体曲线与尺寸。 |
| 方向转场 | [按方向侧向裁切交接整章](../patterns/directional-section-wipe.json) | 遮罩覆盖、内容替换、遮罩退出的方向交接；三章内容与可调时长是本地教学构成，不替代原案例整屏舞台。 |
| 主动声音 | [声音主动启用与随时停止](../patterns/sound-opt-in.json) | 默认静音、用户启用、操作触发、关闭与后台停止；合成短音是本地反馈，未使用来源 BGM、人物语音或操作音轨。 |
| 单开内容 | [单开内容与图像联动](../patterns/single-open-accordion.json) | 当前项展开、其余项收起，正文仍在正常文档流；本地未实现图像联动，也未重现来源的展开曲线。 |

本地示意不是新的品牌案例，也不是每条巧思的精确复现。选择其他巧思时继续阅读其实际机制与来源，不将这五个示意当成所有条目的预览。当前对应关系与实现差异见 [复现边界](../demos/pattern-playground/fidelity.md)。

## 来源与证据

上述取材沿用 `patterns/` 中保存的案例字段定位、归档日期与观察原文，本研究没有重新实访原站。`observed` 表示归档源端观察，`adapted` 表示本地迁移，`inferred` 表示公开资料推断；体验类型和共享示意不改变证据等级。

例如，形状反馈保存 Material 的归档观察；方向遮罩保存明日方舟案例的适配记录；单开内容同时包含 Claude 的推断记录以及 Stripe、Qoder 的归档观察。来源参数仍留在各巧思中，本地参数必须作为本地拟合说明，不以共享示意的运行结果证明原站还原精度。
