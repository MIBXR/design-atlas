# 个人网页风格参考库 · 调研与设计地图

核验日期：2026-10-07。首版范围：4 个产品官网、2 个游戏/IP 官网、8 种经典设计语言，全部配独立本地教学 demo。

## 调研方法

1. 找到真实官网、原作者案例或第一方设计叙述，读取原文；有可视化核验时保存截图。
2. 区分 **观察事实**、**作者解释**、**本库的设计推断**。来源无法打开时明确限制，不把搜索摘要当完整页面观察。
3. 提取产品重点、信息顺序、浏览交互、主题气质，再记录失效条件与实现约束。
4. 迁移机制到原创示例品牌；保留可运行代码、结构化 JSON、Prompt 和实际浏览器预览。
5. 用响应式、核心交互与浏览器错误记录检验实现，再通过 Git 留存。

这里的「有设计感」不代表统一审美或获奖排名。选择标准是：案例可追溯、视觉与内容相互支持、可提炼明确约束，且风格之间具有学习价值。每个条目的来源在其调研文档和参考库详情中近旁标注。

## 怎样判断风格是否适合产品

先回答四个问题：用户要理解什么？最重要的内容证据是什么？需要完成哪个动作？哪种情绪能帮助这个动作？然后选风格，而不是先选颜色。

- 产品本体明确：优先考虑产品主视觉与配置。
- 能力抽象：用真实界面、流程或可操作模型作为证据。
- 世界与人物承载价值：用章节、场景、角色与玩法形成叙事。
- 信息比较频繁：网格、字号差与稳定阅读轴优先。
- 结构关系重要：等轴投影、线描顺序可承担说明任务。
- 情绪与文化强：手绘、拼贴、复古、像素应与内容语义共同成立。

## 共同约束

背景动效不能抢走产品重点。正文与操作区需要稳定命中区、可读行长、明确状态。保留原生滚动，减少动态效果偏好时关闭非必要位移动画。参考 [W3C Animation from Interactions](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)；其 2.3.3 为 AAA 指南，本库借用约束，并未声明完成正式 WCAG 认证。

首版 SVG、CSS 图形与 Canvas 场景由本库自绘；历史资料和官网画面只作为私人研究证据。对外使用前应替换真实品牌、版权图片和未获授权素材。Prompt 包含统一的产品/受众/价值证据/主行动参数壳、完整示范任务和要素协调要求；条目原文还包含具体的负面约束与改造练习。
