# Design Atlas · 个人网页设计参考库

28项本地参考：7个产品平台、7个游戏/IP、6个艺术文化案例、8种经典风格。每项包含真实来源、设计元素、约束、Prompt、独立代码和交互预览。20个品牌与文化案例采用官方素材，另附原站截图、来源清单及复现差异；经典练习研究构成原理。全部通过本地 Git 留存。

## 打开与体验

- Windows 双击 **start.cmd**，打开 http://127.0.0.1:4173 。终端 Ctrl+C 结束服务。
- 已有 Node.js 可运行 `npm start`，不需要安装项目依赖。
- 建议保持这个固定地址使用；音视频、字体、剪贴板和收藏通过本地 HTTP 服务运行更稳定。
- 服务仅绑定 127.0.0.1。若修改端口，新地址会有独立的浏览器收藏。

运行时图片、视频、音频与字体均在对应 Demo 目录。音频必须由用户启用，视频可静音播放；具体来源和压缩/裁剪情况见各例资产清单。部分网页的 CTA 链接真实原站，交易、登录与下载留在原站完成。

## 查询与回看

左侧分类：产品与平台、游戏/IP、艺术与文化、经典设计语言。地区筛选按参考机构或创作来源分组；版本另作说明。它不是给整个国家规定一种视觉风格。搜索可匹配标题、品牌、元素、交互、约束和来源。`/` 聚焦搜索；勾选2–3项并排比较。

详情可操作 iframe；手机模式限制为390px，独立打开查看完整宽屏。原站局部复现提供“对照原站”“复现范围与差异”“素材来源清单”，并可展开原站/本地截图。截图可能采用不同视口，不能当作像素差异计量。原站会更新，来源以观察日期为准。

## 收藏的实现与备份

收藏键为 `atlas-favorites`，值是案例 ID 数组，保存在当前站点的浏览器 `localStorage`。它不上传、不登录、不自动写入 Git。刷新后仍保留；换浏览器、换主机名或端口、清理网站数据、结束无痕会话，会得到独立或空的收藏。浏览器拒绝存储时，本次会话仍可使用并显示提示。

“收藏备份与说明”可导出 JSON，也可粘贴导入。导入合并已有收藏、去重、忽略库中不存在的 ID。把导出的 JSON 自行放入 Git，即可保存个人策展结果。JSON 只含 ID、格式版本和导出时间，没有复制大素材。

## 可交互的设计元素

**fundamentals.html** 把配色、字体、布局、留白、形状、图形、层级、质感、动效做成控件，直接改变同一示例画面。可带入案例色板、单项混搭、查看纯色文字对比度、体验反馈、复制配置和 Prompt。

实验室是元素层面的教学归纳；对品牌整页的信息架构和滚动节奏，应使用对应独立 Demo。详情中的八项元素映射说明哪些元素协同表达同一主题。理论依据见 [设计基础](research/foundations.md)。

## 文件与维护

```text
entries/<id>.json         单一结构化数据来源
research/<id>.md          直接观察、理论、推断与限制
research/screenshots/     原站实访截图
demos/<id>/               独立HTML/CSS/JS、真实素材
  assets-manifest.json    素材URL、用途与处理记录
  fidelity.md             原站/本地逐区域对照与边界
previews/                 本地实际浏览器截图
catalog.js                从JSON生成的离线检索目录
index.html + atlas.*      分类、查询、比较、收藏
fundamentals.*            设计元素实验室
scripts/                  构建、检查、本地Range媒体服务
QA.md                     实际验证及未验证事项
```

新增流程见 [CONTRIBUTING.md](CONTRIBUTING.md)。修改条目并保存实际截图后运行 `npm run build`、`npm run check`；检查覆盖数据、代码、本地引用及素材来源/字节数/SHA256。完整 Demo 要复制整个目录，“入口源码”下载仅用于阅读。

本地 `.git` 保存版本；`git log --oneline` 回看分项提交，`git show <commit>` 对照旧实现。未配置远端。交付 ZIP 含研究、素材、源码、截图与 `.git`；旁边的 history.bundle 可用 `git clone design-atlas-history.bundle design-atlas-restored` 恢复 Git 历史。

## 学习范围

本库用于个人本地学习，不是品牌官方站点。复现选定区域和关键机制，未声明完整像素级克隆；3D、联网内容、商业流程等边界明确记录。官方图片、角色、商标、字体、音视频的权利仍归原权利人，代码许可不授予这些素材的商业使用权。真实素材无需再画一遍，但必须准确、来源可查。

案例地图见 [完整索引](research/CASE-INDEX.md)；地区对照见 [国别案例比较](research/COUNTRY-COMPARISON.md)和[调研总览](research/OVERVIEW.md)。
