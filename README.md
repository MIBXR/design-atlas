# Design Atlas · 个人网页风格设计参考库

一套可以回看、搜索、复用和比较的本地参考库。14 个条目覆盖真实产品官网、游戏/IP 宣传页以及手绘、等轴 3D、线条、几何形变、瑞士、包豪斯、80 年代复古、像素八种经典方向。

## 打开

- Windows 双击 **start.cmd**，浏览器会打开 `http://127.0.0.1:4173`。在终端按 Ctrl+C 结束服务。
- 已有 Node.js：在本目录运行 `npm start`；无依赖安装步骤。
- 也可以直接打开 **index.html**。目录页、检索和多数 demo 可离线运行；推荐本地 HTTP 服务，以获得一致的收藏存储、剪贴板和下载行为。
- 如果 4173 已占用，在 PowerShell 设置 `$env:PORT=4174`，再运行 `node scripts/serve.mjs`，然后打开对应端口。

所有 demo 的字体使用本机字体，无联网字体、CDN 脚本或远程图像依赖。声音只存在于复古合成器 demo，默认静音，需手动开启。

## 浏览与查询

左侧按产品、游戏/IP、经典风格筛选；搜索风格名、真实品牌、设计约束、交互或来源全文。`/` 快捷键聚焦搜索。星标收藏只保存到当前浏览器本地存储。勾选 2–3 项后可比较信息焦点、设计机制、交互、主题及约束。

每个详情页提供：设计机制、凸显产品的方法、浏览交互、主题、适用/慎用场景、颜色/字体/布局/动效 Tokens、完整 Prompt、负面约束、改造练习、来源、可运行 iframe、390px 手机预览、截图、调研文档及代码路径。可以从上一项/下一项依次学习。

## 可交互的设计元素实验室

打开 **fundamentals.html**，或点击目录中的“设计元素实验室”。它把配色、字体、布局、留白、形状、图形、层级、质感、动效直接做成控件，作用于同一份示例内容；桌面版控件和预览并排，手机版纵向重排。

- 切换三套协调方案，观察颜色、字体、形状、间距如何共同表达气质。
- 从 14 个案例带入要素，再单独替换一项，观察组合变化；详情页的实验室链接自动带入当前风格。
- 调整背景、文字、强调色，实时查看纯色文字对比度；切换三种布局和三幅本地 SVG，改变层级、圆角、留白、质感与操作反馈。
- 复制当前配置 JSON 和 Prompt，包含实际参数及参考来源；浏览器拒绝剪贴板时可展开文本手动复制。
- 示例笔记可实际编辑与保存；这是本次页面的临时交互，不是持久化笔记产品。

字体、间距及形状的案例带入是明确标注的教学归纳。完整网页的信息架构和关键交互仍应在对应独立 Demo 中学习。设计框架与依据见 [设计基础调研](research/foundations.md)。

## 目录

```text
entries/                 14 个结构化 JSON，单一数据来源
research/                来源与观察、理论、推断、限制
research/screenshots/    部分实际官网研究画面
demos/<id>/              14 套独立 HTML/CSS/JS/SVG
previews/                实际浏览器渲染截图
catalog.js               从 entries/ 生成的离线检索目录
index.html + atlas.*     本地参考库界面
fundamentals.*          可交互设计元素实验室
scripts/build.mjs        生成目录，不需要打包器
scripts/check.mjs        数据、引用、语法与依赖检查
scripts/serve.mjs        仅绑定 127.0.0.1 的静态服务器
QA.md                    实际验证记录与局限
CONTRIBUTING.md          添加条目的字段与质量约定
```

独立 demo 保留整个对应目录运行；“入口源码下载”用于阅读入口，多个文件的 demo 需要其 CSS/JS/SVG 同时存在。实际截图是代码 demo 的呈现，来源截图另存研究目录，二者不会混标。

## 复用与维护

1. 选条目，先读约束和真实来源，再复制 Prompt，替换产品、受众、内容证据和行动目标。
2. 复制 `demos/<id>/`，把虚构内容替换为真实内容，并保留交互状态、响应式与减少动态效果处理。
3. 新增条目按 [CONTRIBUTING.md](CONTRIBUTING.md) 填 JSON 和调研文档，制作独立 demo。
4. 运行 `npm run build`、`npm run check`；保存实际桌面/手机截图后运行 `node scripts/check.mjs --require-previews`。
5. 用 Git 留存：`git add entries research demos previews catalog.js`，然后提交明确的变更说明。

需要迁移时复制整个目录（包括 `.git`）即可保留历史。`git log --oneline` 查看分项提交，`git show <commit>` 回看来源或实现的演变。该仓库已在本地初始化与提交，未配置远端；如果以后需要云端备份，可配置你自己的远端仓库。

交付的 ZIP 同时包含源码、研究、桌面/手机截图和 `.git`；旁边的 `design-atlas-history.bundle` 是独立 Git 历史备份，可以用 `git clone design-atlas-history.bundle design-atlas-restored` 恢复。

## 研究范围与素材

本库学习设计机制，使用原创品牌和自绘图形。不是品牌官方页面，也不宣称像素级复刻。部分经典案例仅提供局部视觉理论；每篇调研注明直接观察与推断边界。官网会变化，后续复用时根据核验日期决定是否刷新来源。

代码与原创图形可作为个人学习和项目起点；真实品牌商标、链接目标和来源截图仍归相应权利人。没有复制游戏角色、官网视频或商品摄影到 demo。完整风格地图见 [调研总览](research/OVERVIEW.md)。
