# 绝区零首页复现说明

参考：[官方桌面首页](https://zzz.mihoyo.com/main)、[官方移动首页](https://zzz.mihoyo.com/m/main)，2026-10-11快照。非官方网站。用户确认范围是完整首页体验，独立子页链接官网。

## 当前实现

保留六章、62名角色、9部影像、6条新闻、3张设定和4组特色，以及原始图片、字体、BGM、几何构图、桌面与移动布局。首页PV配置为空，因此首屏不显示播放入口。人物、头像窗口、影像、新闻、世界、特色各自保存状态；桌面编号轨道定位章节，手机菜单和底部下载栏按源规则出现/收起。

来源HTML/CSS的视觉结构与原始资源保留，交互调度由本地原生JavaScript实现。角色500ms、阴影300ms、轮播300ms、章节650ms及视差幅度来自公开源码；IntersectionObserver的入场触发、轮播循环边界的接续与原生dialog为本地适配，不能称为源端Vue/Swiper/GSAP运行时原样移植。全部内容与主要状态都有本地入口；不作逐像素、逐帧完全相同的保证。

背景音乐默认关闭，由用户启用；影像播放静音BGM，关闭按先前意图恢复，后台暂停。影片为官方流式地址，未转码或裁剪，也未打包进离线导出。网络失败会保留官方入口；网络可用性与浏览器媒体解码独立于本地文件hash。未发现足以确认角色或按钮短音的来源，不臆造操作音。

## 操作与回程

| 操作 | 本地实现 |
| --- | --- |
| 首次进入 | 邦布30帧精灵等待主视觉和字体；图片失败也退出加载层，让其余内容可读 |
| 角色 | 头像点击同步身份；翻页每次3张而不换人；方向键/Home/End支持选择与焦点 |

| 新闻 / 设定 / 特色 | 分页或左右箭头，手机手势，当前文字与画面同步，相关内容外链 |
| 章节 | 编号 / 上下箭头 / 回顶；当前章与滚动位置同步，快速新选择取消旧滚动 |
| 菜单 / 弹窗 | 关闭、Escape、焦点返回；手机菜单Tab留在面板内 |

## 验证与限制

本地在Chromium浏览器检查独立页面及站内嵌入。手机390px确认六章布局、无整页横向溢出、菜单打开/关闭与焦点返回；桌面1440×900检查章节回程、角色选择/窗口翻页、新闻/设定/特色换态、适龄弹窗和BGM启停；BGM实际currentTime前进，影像打开静音、关闭释放播放器。

源站移动页在当前浏览器设备模拟中触发“请将手机/平板竖过来”的方向提示：CSS视口与screen.orientation为竖屏，但旧window.orientation属性不可用。未修改或隐藏该提示；移动DOM、样式、素材和组件行为已读取，源站手机底层画面的同条件截图逐帧对照仍未完成。首部官方影片已在本地浏览器解码为1920×1080并确认播放时间推进，关闭后播放器释放；其余8部逐部播放、连续流畅播放与外部CDN长期可用性未验证。BGM本地音轨可推进。真实手机、Safari/Firefox及多操作系统未验证。

登录、支付、下载安装和独立内容页面由官网负责；本地不提交这些业务数据。加载错误恢复、键盘与焦点管理是本地补充，不冒称所有无障碍分支在原站均已实测。

## 源码与素材

- `index.html` / `mobile.html`：完整两套首页结构。
- `reference.css` / `reference-mobile.css`：本地化后的来源样式。
- `app.js` / `state.css`：本地状态、交互、响应式切换及无障碍适配。
- `data.js`：固定人物、媒体、新闻、特色与官方入口。
- `assets-manifest.json`：原始素材的来源、大小、SHA256与权利边界。

完整导出保留所有归档资源；`--code-only`省略素材。两种模式均不包含远端影片文件。更多构成与定位见[案例研究](../../research/zenless-zone-zero.md)。
