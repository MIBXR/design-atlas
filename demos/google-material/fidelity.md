# Material Design 3 首页局部复现

参考：[官方首页](https://m3.material.io/)。观察日期 2026-10-07，国际英文版，已显示 I/O 2026。机构 Google，国家分类美国。个人本地学习，不是 Google 官方服务。

| 区域／行为 | 保留 | 近似／差异 |
|---|---|---|
| 桌面导航 | 88px 固定侧栏、真实 Symbols 图标、短标签、底部主题／动效圆开关 | 官网目录点击会进入对应文档路由；本地打开一个模态目录，保留当前首页并提供真实官方链接，不实现官网整套文档路由 |
| 手机导航 | 64px 顶栏、左侧目录、清晰当前项与二级入口、主题／动效控件 | 本地使用原生 dialog 做焦点约束和 Escape 返回；菜单约宽度为视口减 56px，未照搬 Angular 动态导航实现 |
| Hero | 两个 24px 大圆角面板、8px 间距、中性surface／on-surface与紫色主动作配对、Google Sans 大标题、80px 主按钮与真实视频 | 描述文案改写，文字换行与纵向位置略有不同。浅色为本地初始方案，不推断官网用户偏好；没有自创抽象 Google hero |
| 视频 | 官方 9 秒 MP4、4000×2000、静音循环、独立播放／暂停 | 减少动态时本地初始停播；静态 poster 取首页官方元数据图，而原站第一帧与视频具体时间可能不同。未转码、无伪造声轨 |
| 内容节 | 官方区域顺序与 20 张配图；I/O 一个横向资源再两项；Expressive/组件 2＋3 分组；最后入门两项加左侧单项 | 较长营销文案与标题改写，卡片文本高度因此可能不同；外链保留内容目标但移除 utm 跟踪参数 |
| Motion | CTA 48→16px 圆角按压、卡片 24→48px 焦点／按压、原始时间曲线，真实视频动态、主题及暂停反馈 | Ripple 为独立 300ms 近似实现；目录用模态覆盖而不是推开文档。没有把规范 spring 系统强行塞进未观察到的首页行为 |
| 页尾 | 信息简介＋四列资源目录与策略链接 | 文字改写；Google 文字为字体排版，未复制页尾 SVG；省略研究招募、Feedback、RSS；增加显式本地学习标识和返回设计库入口 |
| 无障碍 | 跳转主内容、原生控件、可见焦点、状态标签、键盘菜单、触摸点击、reduced motion、自然滚动 | 不声明通过完整无障碍审计；人工视口测试不等同真实手机硬件触控测试 |

原站研究 Edge 有 Dark Reader，源截图不可用于官方取色。本地通过 `darkreader-lock` 维持已核验的官方原始 CSS token；不修改用户浏览器设置。库的主要原站对照使用根节点独立 IAB 保存的 `research/screenshots/google-material-clean-source.jpg`，作为干净原色补充；原有 Edge 首屏、手机与交互证据仍保留。

本地仅使用独立 HTML/CSS/JS 和归档媒体／字体，不运行原 Angular 脚本、不嵌入整页、不包含统计或营销追踪。素材保持原字节，实际来源、大小、SHA256、用途和权利见 [assets-manifest.json](assets-manifest.json)。公开可获取不等同素材商业使用许可。
