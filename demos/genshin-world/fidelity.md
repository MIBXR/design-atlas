# Genshin 复现边界

- 来源 URL：https://genshin.hoyoverse.com/en/
- 采集日期：2026-10-07；仅此一次版本快照。

## 来源确认与本地实现

| 源行为 | 本地实现与准确性 |
| --- | --- |
| 6 章垂直 Swiper，document.scrollY=0，末尾部分 footer | translate3d 的 3 核心章节加 footer，正反滚轮/手势，有限末尾位移；不再以长页 scroll-snap 冒充 |
| 两角色选择连同整背景、肖像、文字换态，立绘 100ms opacity | 原始两背景/两立绘/两肖像/麦克风同步；100ms 交叉淡化 |
| 每人 3 条官方 MP3，随机；播放中再点暂停 | 用户点击原始麦克风随机选择对应文件，二次点击暂停；换人/离屏/后台停止是本地防叠加补充 |
| 静音主视觉视频 | 本地 3 秒无声片段，真实暂停、离屏停止；没有背景音乐按钮 |
| 日历与角色详情入口 | 原始日历可放大；人物 dialog 只含摘要和官方详情外链 |

## 明确近似和未覆盖

整屏 Swiper 精确时长未核验，本地 600ms ease + 650ms 输入锁不是源参数；最新请求队列、键盘导航、dialog 焦点、减少动态和手机排布为本地补充。源的登录福利、Xbox、完整武器、领奖/登录、Wiki 全页未复制。桌面画布未逐像素保持源 1920 基准的 810px letterbox 比例。

固定主题；角色换色保留 IP 美术，不加深浅主题开关。原始台词服务人物认知，主视觉静音；两者不能混称 BGM。素材 URL、字节、SHA-256 与用途见 assets-manifest.json；未加载原账户与追踪服务。
