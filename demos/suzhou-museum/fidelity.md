# 苏州博物馆：当前实现范围

采集：**2026-10-09**，[中文官网第3章](https://www.szmuseum.com/Home/Index#page3) 与第4章，以及[建筑介绍](https://www.szmuseum.com/Other/MuseumIntro)。固定快照。完整首页四章；本地只取图像目录和建筑/到访两章。

| 触发 | 原站观察 | 本地对应与边界 |
|---|---|---|
| 进入图像目录 | 白色界面，多尺度图像与常显类别构成目的地入口。 | 六项方角瓦片、窄白缝、实际官方图像；不复制首页和展览自动轮播。 |
| 选择目的地 | 资讯、课堂、馆藏、展览、文创、建筑等进入不同页面。 | 五项外链官方、建筑入口进入第二章；未复制账户、商城、课堂业务。 |
| 正反章节定位 | 桌面 fullPage 四个整屏推进，章节入口可达。 | 两章原生 scroll-snap:proximity 与章节入口近似，不宣称复现滚轮接管时序。 |
| 建筑与到访 | 第4章展示开放时间和预约；建筑介绍说明粉墙黛色、边饰与自然光。 | 建筑摄影/说明及官方到访链接；不把观察日信息冒称当前实时开放状态。 |
| 建筑观察 | 官方内容在独立建筑文章中。 | 深色框线组件和观察 dialog 是原创迁移，关闭/Escape 返回原按钮。 |
| 手机与减少动态 | 原站手机/触屏未完整实访。 | 本地两列图像矩阵后自然长页；取消吸附和滚动平滑，入口名与内容保留。 |

浅色主题、原色摄影、方形框架和少量陶红信号固定；观察范围未发现独立音频控制，本地无 BGM。系统中文字体不复刻字标笔迹。公开图像的原字节、尺寸、归属和 hash 见[素材清单](assets-manifest.json)。

本地在 1440px 桌面和 390px 手机实际浏览器验收：素材可加载、无整页横向溢出，键盘 Enter 可打开建筑观察窗，关闭/Escape 可返回。桌面与手机标准预览来自实际浏览器。公共素材映射、回退和缓存异步接入，不叠加品牌载入动画。
