# 故宫探索页：复现范围与证据

固定采集日 **2026-10-09**，来源[中文探索页](https://www.dpm.org.cn/Explore.html)。本地复现这一页的**建筑、藏品、典籍、历史、文物医院、文化专题六章**，以及顶部导航、菜单、搜索入口和页尾；不把账户、预约、独立馆藏平台或外链详情称为已复制。

本轮读取运行 DOM、计算样式、原 CSS 与 mScroll/xRoll 配置，并实际操作菜单、悬停、滚动、轮播点、键盘与手机布局。原图饰、两套文化专题图、真实藏品、历史与医院摄影均本地化，字节、尺寸、出处与 SHA-256 见[素材清单](assets-manifest.json)。朱红纹理、屋脊比例、1258px 内容框、中文字体栈、标题饰纹、六章间距采用源规则。

| 机制 | 本地实现与核验 |
|---|---|
| 导航与菜单 | 桌面对应子导航、200ms 离开收起；手机栏目开关；正文锁定、关闭/Escape 与焦点归还实际通过。 |
| 藏品叠层 | 原两张摄影、50% 黑色叠层与 500ms 淡入，文字可在内部滚动；滚动条采用原生实现。 |
| 典籍 | 原八条、1s 位移/透明度、0.3s 序列，回看越过触发线可复位；采用本地观察器组织源动作。 |
| 文物医院 | 原两张图与两点，500ms 水平切换、5000ms 自动循环、悬停/焦点暂停；点、图与 pressed 状态同步。 |
| 文化专题 | 器物、书画、文化、人物、展览五项，桌面半幅纸签与独立手机图完整保留。 |
| 搜索与外部能力 | 非空搜索去官方检索；无障碍入口明确进入官方工具，不复制第三方语音/读屏服务。 |

独立浏览器在 **1440×1000** 对照确认六章 top/height/width 相同；**390×844** 首四章相同，医院高度相差约 **0.49px**，专题高度相同，无整页横向溢出。轮播第2图真实轨道变换、菜单关闭与返回顶部已核验。测量是这些状态的证据，不能推广为每个浏览器、字体或所有外部页面逐像素相同。原站/本地截图与几何 JSON 在仓库外 work/fidelity/independent-audit/；正式预览由实际浏览器生成。

已知差异：第三方页尾蓝色认证图本次未取得可分发响应，保留文字认证链接；原站内部滚动插件替换为原生滚动；典籍用本地观察器实现相同动作参数；新增键盘可达性与减少动态规则。固定浅色和原色影像，无额外声音。完整状态、来源和此前遗漏原因见[状态矩阵](state-matrix.md)。

此前首版主动缩成三章并加了原站不存在的藏品观察 dialog，错误地把网站复现当作可任意简化的教学表达；本轮删除该替代并恢复六章。
