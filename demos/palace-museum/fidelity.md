# 故宫：当前实现范围

采集：**2026-10-09**，[中文探索页](https://www.dpm.org.cn/Explore.html)。固定快照；本地选建筑、藏品和文化专题三段。

| 触发 | 原站观察 | 本地对应与边界 |
|---|---|---|
| 首次进入 | 白底探索目录，朱红建筑面内有名录与右下屋脊摄影。 | 保留构成和实际透明 PNG；标题文案、字号、系统字体与朱红数值为本地拟合。 |
| 上下与反向浏览 | 建筑、藏品、典籍、历史、文物医院、文化专题为原生长页。 | 缩为三段，原生文档流和章节锚点；不加全屏转场。 |
| 选择建筑名称 | 真实链接进入建筑记录。 | 三个建筑名称与目录链接回官方，不复制建筑业务。 |
| 选择文化专题 | 作品图与右半浅纸签、竖排类目并置，可进入五类专题。 | 保留三类与实际公开图像；轻微 hover/focus 缩放是本地补充。 |
| 观察藏品 | 原站藏品入口可进入正式记录。 | 青釉盘观察 dialog 是教学补充，关闭/Escape 归还焦点，并提供官方完整记录。 |
| 手机与减少动态 | 原站手机与触屏未完整实访。 | 本地文字与屋脊分区，保留可读纸签；减少动态取消平滑和缩放过渡。 |

固定浅色、朱红建筑区与图像原色；观察范围无独立声音控制，本地不添加声音。官方公开图像保留原字节和尺寸；字体/品牌文字为本机回退，不声称像素级或整站还原。图像归属与 hash 见[素材清单](assets-manifest.json)。

本地在 1440px 桌面和 390px 手机实际浏览器验收：素材可加载、无整页横向溢出，键盘 Enter 可打开观察窗，关闭/Escape 可返回。桌面与手机标准预览均来自实际浏览器。公共素材映射、回退和缓存作为异步依赖接入，不增加阻断式开场。
