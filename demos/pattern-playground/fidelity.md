# 巧思共享示意：实现与边界

[独立入口](index.html)与网站内嵌示意共用 [JavaScript](../../pattern-playground.js) 和 [样式](../../pattern-playground.css)。五种示意用本地内容解释机制，取材依据见 [研究](../../research/pattern-experiences.md)。它们没有新增案例或巧思，来源快照、日期与证据等级仍以原巧思记录为准。

| 示意与触发 | 来源机制 | 当前本地对应与边界 |
| --- | --- | --- |
| 视觉：选择强调方式或调整圆角 | [单一信号色集中强调](../../patterns/restrained-signal-color.json)用稳定中性色与少量强调色区分重点。 | 可切换强调色、下划线或无强调，容器圆角为 0–32px；下划线、几何装饰和圆角控制是本地补充，不是来源原样构图。 |
| 微动效：悬停、聚焦或模拟进入／离开 | [按压与聚焦改变容器形状](../../patterns/state-shape-feedback.json)让控件形状与操作状态共同反馈。 | 浮起 8px、220ms 后回落，或圆角由 12px 变为 32px；这些数值是本地拟合。选择状态使用文字与 `aria-pressed` 表达，减少动态保留状态并关闭位移与过渡。未复现来源 CTA 48→16px、资源卡 24→48px 的具体反馈。 |

## 当前验证边界

Chrome 内置浏览器的 48kHz 实时输出采样包含 6064 个非零样本，峰值为 0.078891，确认合成短音产生了送往音频输出的信号；这不是对设备扬声器的主观试听。静音行为与键盘按钮状态已有浏览器核验。

已在 1440px 桌面与 390px 手机浏览器核验布局、视觉参数、微反馈进入与离开、键盘选择、页面转场正向／回程／快速最后目标、减少动态、默认静音与重复确认。离开类型或详情后释放控件与内嵌 Demo，返回声音类型保持静音。实验室导出的协调示例不带声音，来源声音行为单独保留为取材信息。

真实后台／返回行为未完成浏览器核验：当前控制环境新建另一标签页时，原页仍报告 `visibilityState=visible`。后台静音是当前实现，但这次环境不能证明真实后台切换有效。没有重新核验各原站音乐或操作音，也未做设备扬声器主观试听；这些示意与输出信号核验不表示原站声音或动效的精确复现。
