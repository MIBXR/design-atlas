    等待开始 · 0%

    后台自动暂停

    无需联网

    PROGRESS + ACTIONS + STATUS

    把等待变成可控状态

    比较实心与分段进度，启动、暂停、重置；也可以手动前进。进度数值来自本地计时器，原库只提供样式。

    减少动态时采用手动步进；切换用法或页面进入后台立即暂停，返回后由用户继续。

    可调参数
    进度 0–100%，每步 10%；自动每 240ms 增加 2%，均为本地演示值。
    适配
    真实项目应连接真实任务进度，禁止把模拟进度当作完成证明。
