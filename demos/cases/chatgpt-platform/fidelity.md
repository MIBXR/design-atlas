# ChatGPT：复现范围

## 对照结论与差异原因

源端记录的 rail 标题过渡为 360ms，窗口切换按滚动阈值触发，人工选择后观察超过 40 秒仍保持模式；本地窗口 720ms、阈值 340px 和 6500ms 自动周期属于另一组实现参数。窗口与拼贴机制可对应，时序及自动行为未达 1:1；同视口成对结果未记录。

| 差异或删减 | 原因 |
| --- | --- |
| 主窗口、周边轨迹／交错、自动周期与源端记录不同 | 本地采用拟合；选择这些参数的原因未记录。 |
| 已决定删减三个静态故事卡 | 原因未记录。 |
| 已决定删减账户、付费与下载服务 | 产品截图用于页面展示，业务入口指向官方。 |

页面布局、窗口交接、拼贴轨迹、轮换与暂停均由本库自行实现；中央产品图取自官方截图。

## 本地实现与对照

720ms 主窗口过渡、340px 交接阈值、周边层的轨迹/交错及 6500ms 自动周期为本地拟合；中央产品图是官方截图，不是可登录、对话、编辑的完整产品。没有复制账户、付费和下载服务，原站三个静态故事卡未移植。暂停控制停止自动轮换和周边运动，正常滚动仍可阅读。
