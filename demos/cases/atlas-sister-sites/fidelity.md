# Atlas 姊妹站 · 复现范围与对照

Demo 把两站界面抽象为列表、详情与文档三页。作品内容、分类数量、三项导航、品牌切换、右栏长度按钮与 CSS 图版为本案例的教学内容。

## 同视口数值

对照条件为 1440×900 CSS 像素、DPR 1、缩放 100%、中文、浅色主题、页面顶端。线上页面分别为 Web Atlas 与 Motion Atlas 的案例库、详情与文档；源码数值锁定为条目中的两个提交。

| 项目 | Web 线上实测 | Motion 线上实测 | Demo 实测 | 一致性 |
| --- | --- | --- | --- | --- |
| 顶栏高度 | 68px | 68px | 68px | 一致 |
| 顶栏左右内边距 | 32px | 32px | 32px | 一致 |
| 列表侧栏 | 宽 228px、left 32px | 宽 228px、left 32px | 宽 228px、left 32px | 一致 |
| 卡片圆角 | 10px | 16px | Web 10px／Motion 16px | 一致 |
| 卡片四边内边距 | 16px | 16px | 16px | 一致 |
| 详情两栏比例 | 889.328／444.656px，2:1 | 896／448px，2:1 | 889.328／444.656px，2:1 | 比例一致；Demo 沿用 Web 的稳定滚动槽 |
| 文档正文最大宽度 | 860px；当前实宽 846px | 860px；当前实宽 856px | 860px；当前实宽 846px | 上限一致；实宽受滚动槽占位影响 |

390×844 下 Demo 顶栏仍为 68px、水平边距 16px，详情操作栏高 69px；操作栏和舞台工具条各一行，布局无横向溢出。桌面详情操作栏同为 69px，吸附偏移为 `68 + 69 + 24 = 161px`。

两种长度均保持舞台列 `scrollHeight = clientHeight = 710px`。长说明滚动 400px 时舞台 top 仍为 161px；页面底部两栏 bottom 同为 715.484px。短说明同时吸附，到底时两栏 bottom 同为 715.594px，底边差均为 0。

## 抽象边界

- 顶栏仅保留三种页面，右侧增加 Web／Motion 分段切换。品牌路径、主题值与圆角沿用来源。
- 列表用 12 个虚构名称与 CSS 几何画面展示相同卡片机制；来源标签、比较工具与 Motion 能量曲线由两站原作承担。
- 详情舞台固定为 16:10，支持手机画面、播放／暂停；右栏的 8／2 节切换用于演示两栏长短。Prompt 可复制，收藏可导入和导出。
- 文档使用示例文章与 h2／h3 本文目录；正文为透明底。表格和代码块按本案例要求使用次级面和 `--r`，线上阅读器使用内容面和 `--r-lg`。
- Demo 在 ≤800px 保留顶栏，单行详情操作栏持续位于其下；两站手机顶栏按滚动方向显隐。跨文档过渡在两站原作中使用，Demo 演示同文档 hash 切换。

## 模块与状态对照

| 模块／状态 | 原作定位与触发 | Demo 对应 | 结果 |
| --- | --- | --- | --- |
| 列表骨架 | 两站案例库顶端；顶栏、左侧栏与卡片网格 | `#list` | 桌面／手机、双品牌双主题均到达；共用尺寸与各站品牌圆角；搜索命中 1 项、游戏筛选 3 项，名称反序与正序相反 |
| 配色角色 | 固定提交的主题变量；深浅切换 | 四组品牌／主题变量 | 系统→深→浅→系统循环、系统深浅变化与品牌替换均生效，切换不新增导航记录 |
| 导航当前项 | 顶栏实心、侧栏柔和；悬停非当前项 | 顶栏、分类、文档目录 | 中性悬停；卡片白底保持不变、位移 -3px、画面矩阵 1.025；按钮悬停为柔和底与深色强调字／边框 |
| 两栏详情 | 页面滚动、说明长短变化 | `#detail`、右栏长度按钮 | 舞台始终吸附、短说明同时吸附、到底底边对齐；上一项／下一项、画面宽度、播放／暂停均可操作 |
| 收藏与 Prompt | 两站侧栏收藏与详情主操作 | 列表／详情收藏、导入／导出、复制 | 收藏状态共享；导出编号数组，导入合并为 2 项；剪贴板取得完整 Prompt |
| 文档阅读 | 左目录查找、右目录定位 | `#docs` | 标题搜索命中“吸附规则”；目录滚动 250px 时搜索框 top 93px、研究标题 top 161px，无重叠；章节定位后当前项同步 |
| 页面交接 | 顶栏命名快照与根过渡 | 三页 hash 切换 | 实际根动画 140ms ease-out、顶栏 top 0 且快照无动画；减少动态为 0 个动画，不支持 API 时也到达文档页 |
| 手机导航 | 390×844 菜单两视图 | 顶栏菜单、底部品牌与主题 | 本页单列、全站两列；品牌／主题可操作；Escape 收起并返回按钮焦点；本文目录与菜单互斥，选择章节后收起 |
| 阅读器与嵌入 | 本库案例详情与 Markdown 阅读页 | 案例 iframe、研究链接 | 本案例 Demo 可嵌入；研究的 10 个英文 id 均在阅读器中可达 |

桌面 1440×900 与手机 390×844，各完成 Web／Motion × 浅／深 × 三页的 24 组视口及整页截图；独立 Demo 的该轮页面脚本错误为 0。每页设计决策默认收起，展开为 3 条，各链接直达研究阅读器章节。
