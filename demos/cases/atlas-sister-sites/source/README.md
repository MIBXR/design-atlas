# 配色研究原件

这三个 HTML 保存独立的配色与状态对照，可直接在浏览器打开。

| 文件 | 用途 |
| --- | --- |
| [index.html](index.html) | Web／Motion、浅／深主题的底色、卡片与侧栏方案；同一画面比较纯白、纯黑与灰色作品的边界。 |
| [emphasis.html](emphasis.html) | 比较 A 全实心、B 顶栏实心与侧栏柔和、C 全柔和的当前项层级。 |
| [accent-tiers.html](accent-tiers.html) | 查看主题色角色、使用位置与页面脚本计算的对比度。 |

从仓库根目录运行 `PORT=4393 node scripts/serve.mjs`，访问 `http://127.0.0.1:4393/demos/cases/atlas-sister-sites/source/`。单个文件也支持直接打开。

原件来自本案例的配色研究输入。最终界面变量与决策依据见[研究文档](../../../../docs/cases/atlas-sister-sites.md)。
