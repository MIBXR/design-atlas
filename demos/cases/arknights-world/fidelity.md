# 明日方舟 · 全屏档案与交互点阵

| 机制 | 本地对应与边界 |
| --- | --- |
| 开场载入 | 使用原始 SVG 字标与五项实际本地图片预载；百分比跟随资源完成，最短展示 1300ms、就绪延迟 300ms、遮层退出 1000ms。最短展示与百分比平滑是本地预算，不冒称官网网络耗时。 |
| 六章转换 | INDEX → INFORMATION → OPERATOR → WORLD → MEDIA → MORE → 页脚，完整正反路径；固定内层 100vw，使用互补 clip-path 裁切复现源站 SectionItem 宽度蒙版。横屏 1000ms、竖屏 600ms；CSS 曲线近似官网 easeInOutQuad。原生文档不滚动。 |
| 右侧滚动编号 | 保留 300ms 出/入与组间 100ms 错开，文字更新属于同一章节事务；局部时间线以结束时归位保障短屏和快速导航一致。不是瞬间替换数字或普通淡入。 |
| WORLD 点阵 | 隔离官网公开 Three.js 渲染模块；10,000 点池，真实七组 JSON 几何、原始粒子纹理、颜色、变形公式与摄影机布局。目录模型 1785 点，六项模型 3200–5652 点；没有用 CSS 晶体替代。目录预览沿用公开弯曲/RGB 位移 shader。省略独立的 20 点萤火背景。 |
| 世界词条 | 六条官网说明、原始几何、箭头、进度与桌面返回；竖屏与官网一样直接进入源石详情，模型上方、说明下方。快速选择保留最后一次目标。中文使用系统字体，未打包完整中文字体。 |
| 干员档案 | 三位干员、各 E1/E2、官网焦点裁切参数与三段官方日语配音；档案进入每块 200ms 错开，500ms 曲线是本地近似。未复现六人、E0、全部语种和完整档案。 |
| 音乐 | 真实 195.65 秒 BGM，未取得公开曲名；本地默认静音，需点击开启。跨章连续播放，不虚构章节音效。配音、动态暂停与 BGM 相互独立；离开前台暂停声音，返回需再次开启。官网源码确认 BGM 渐变；未核验到专用点击/章节音效。 |

本地 INFORMATION 为一张官方活动图与三则可筛选新闻；MEDIA 保留四类原始图像链接，网格编排近似官网桌面物件，不复现深层画廊/播放器；MORE 保留四项入口及竖屏素材，页脚采用 260px 本地托起布局。账户、支付和站外业务由官方链接承接。

键盘可用 PageUp/PageDown、方向上下、Home/End 切章，WORLD 左右切词条，Escape 关闭目录/页脚。滚轮、触控只由章节舞台消费，内层可滚内容优先；快速反向输入与导航由单一控制器串行收束。动态暂停停止 PV 与点阵，不静音 BGM；减少动态显示同一静态几何，取消蒙版/编号/档案运动，仍保留所有选择和声音开关。URL `.?motion=reduce` 可直接体验该分支，不代表操作系统偏好已被模拟。

本地包含失去前台时的暂停与 50px 触控阈值处理；本次 IAB 多页仍报告前台可见，真实后台 visibilitychange 与触屏硬件手势未获得现场验证。390px 是实际浏览器视口，非操作系统或触屏设备仿真。

官方视频为本地约 18.13 秒 1440×810 静音片段；完整 PV、图像、字体和音轨的来源、处理、尺寸及校验见[最终资产清单](assets-manifest.json)。素材权利归相应品牌与作者，学习使用不代表通用开放许可。
