# 当前复现范围：官方影像的网页转译／教学改编

制作输入、固定来源日期与处理命令见 [source/README.md](source/README.md)；命令输出到独立工作目录，具体输入与参数以该页为准。

本案例是官方影像的网页转译，以官方影像为素材；四个场景的整帧画面取自官方影像作为素材。

## 对照结论与差异原因

原片与本地的同尺寸解码帧已有单帧压缩比较，结果见“源端媒体与本地场景”；媒体构图与片内运动沿用原影像。原作是连续影片，章选、热点、阅读显隐与科室节点操作由本库自行实现，属于网页转译的新增交互。选段压缩、镜头间隔删减与无音轨使整体不同于完整影片的 1:1 播放。

| 差异或删减 | 原因 |
| --- | --- |
| H.264 片段相对 HEVC 原轨道有压缩差异 | 使用已记录的 CRF18 转码；整帧 PNG 来自播放器原尺寸解码。 |
| 已决定删减选段外的完整叙事与音频 | 当前仅保留四个观察场景，完整声音和叙事使用官方入口；选段取舍的进一步原因未记录。 |
| 未重建 3D 工程／渲染器，字标保留在影像中 | 本案例以影像素材进行网页转译；未取得官方字体包。 |
| 科室移动节点周围使用小范围背景补丁 | 用于遮盖原节点并显示当前科室状态，几何／材质没有重建。 |

章选、播放器控制、热点、遮罩、文字终端和节点移动由本库自行实现；影像场景的构图、材质、字标及片内运动直接使用官方素材。

`implementation: reference-study`，`studyScope: visual-adaptation`。主来源为 [官方特别映像《莱茵生命：访问》](https://www.bilibili.com/video/BV1rr4y1b7sz/)，明日方舟官方账号 UID 161775300 于 2022-04-26 发布。于 2026-10-09 实际观看、采集并复核。补充 [2023 四周年官网](https://ak.hypergryph.com/special/4th-anniversary/index.html) 的孤星活动章节只作为来源比较。

未确认可直接逐点击对照的官方莱茵品牌网站。这里保留官方影像构成和片内运动，网页按钮、阅读、显隐和节点位置切换属于本地教学改编。标题、首屏、条目与来源区均标明这一边界。不把二创站、影片身份确认或本地目录包装为官方网页功能。

## 源端媒体与本地场景

原播放器实际使用的公开视频轨道为 HEVC Main、1920×1080、25fps、318.8 秒，25,735,789 字节。完整原轨道归档于仓库外；原始 SHA256、去除签名／查询参数的资源路径见 [assets-manifest.json](assets-manifest.json)。它是无音频的视频轨道；完整声音留在官方播放器。

以下为本库选段边界，不声称恰等于原作镜头切点。片内不加速、重定时或改色；H264 CRF18 转码保留原尺寸、帧率和 1 倍速度，但不等于保留原视频字节。

| 场景 | 原作区间／时长 | 原帧 | 本地保留与边界 |
| --- | --- | --- | --- |
| 许可环线 | 19.20–23.40 秒／4.20 秒 | 22.00 秒 | 原片段／帧保留弧环和速度；章选不是认证 |
| 档案阵列 | 27.00–39.20 秒／12.20 秒 | 35.00 秒 | 原片保留透视、材质与字形，没有换成五张泛化卡片 |
| 双环光学 | 39.20–51.52 秒／12.32 秒 | 48.00 秒 | 原片保留光学；没有声称 CSS 重写 3D 渲染器 |
| 机构矩阵 | 59.60–73.40 秒／13.80 秒 | 68.00 秒 | 全十模块与完整字标由媒体保留；DOM 赋予操作语义 |
四个 PNG 是官方播放器已解码 video 的原尺寸 canvas 导出，未缩放、裁切或改色。四片段合计 16,884,974 字节，采用 ffmpeg 7.1、libx264、CRF18、yuv420p、faststart 转码，参数逐项入清单。双环请求截取12.30秒，按25fps输出308整帧／12.32秒，上表、范围条与时间码按实际51.52秒末端记录。源 32.00 秒帧与本地档案片段 5.00 秒帧以相同 1920×1080 解码比较：PSNR 41.39dB、平均绝对通道差 1.46；仅衡量单帧压缩差异，不代表全片无损。

矩阵互动层为了把原作橙色构件移至当前科室，会遮盖 BSN 附近原节点的小范围背景，该覆盖并非材质完全重建；“仅显示原作画面”同时隐藏补丁／移动节点，显示完整源帧。节点 PNG 是68秒帧的62×63原比例裁切，坐标见清单。原字标保留在媒体中，下方系统字体目录承担语义，未取得官方字体包。

## 响应式、声音与未复现范围

桌面在首屏保留原比例画面与外围控制，手机全幅16:9，不竖裁原片。小屏字标随画面缩小，下方正常字号科室按钮／全称／解释提供等价阅读；不是影片的官方响应式网页。页面自然纵向滚动，没有横向档案架或整页滚轮锁定。

固定暖米白。四片段无音轨，完整声音／叙事在官方链接。未复现全部318.8秒、音频、3D工程／渲染器、真实权限认证及周年网站完整流程，未完整核验周年播放器／手机行为。孤星背景仅用于辅助来源卡，不是档案／矩阵交互证据。

## 对照结果

真实浏览器确认媒体1920×1080、readyState4；播放暂停、章选、重播、时间码／范围条、快速切换、阵列显隐、方向键与展开正常。五项5→1循环可用；矩阵十热点／十目录项齐全，ECO／NRG同步全称、两组状态与节点。

390×844保留全幅构图且无横向溢出；减少动态初始静态，连续停用。独立浏览器从许可起始实际自然播放四段，最终matrix currentTime13.8／ended=true／paused=true／continuous=false；未用脚本seek或直接播放。单段网络阻断产生失败提示，静态退路仍显示1920px原帧与五项入口；解除阻断／恢复缓存并刷新后正常播放。原作／本地同尺寸解码比较另归档于仓库外，页面预览需随本次实现重新生成。
