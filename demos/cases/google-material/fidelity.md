# Google Material：表现力与组件秩序：复现范围

## 对照结论与差异原因

本地与原作对应首页视频、圆角／角色颜色、按钮反馈和系统主题机制；原作目录及二级主题使用 Angular 路由，本地采用 dialog 和官方链接，正文也有改写，整体未达 1:1。同视口成对结果未记录。

| 差异或删减 | 原因 |
| --- | --- |
| 点击位置涟漪使用本地 300ms 近似 | 原因未记录。 |
| 已决定删减 Angular 完整文档路由，以本地 dialog 承接二级入口 | 路由缩减及正文改写的原因未记录。 |
| 已决定删减外链页面的本地副本 | 保留官方链接；省略本地副本的原因未记录。 |

页面、dialog、点击位置涟漪和主题接入由本库自行实现；配色／圆角依据原 CSS，首页 MP4 使用官方素材。
