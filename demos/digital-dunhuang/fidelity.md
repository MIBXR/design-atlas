# 数字敦煌：当前实现范围

采集：**2026-10-09**，[首页](https://www.e-dunhuang.com/index.htm)、[洞窟目录](https://www.e-dunhuang.com/section.htm) 与[第257窟壁画查看器](https://www.e-dunhuang.com/showmural/10.0001/0001/0001/0257/0001/0003/01)。固定快照，独立云游戏不在范围内。

| 触发 | 原站观察 | 本地对应与边界 |
|---|---|---|
| 首次进入 | 全幅石窟影像、中心检索、多图轮换。 | 一张官方静图/中心搜索；轮播明确省略，不增加另一套欢迎或加载机制。 |
| 条件选择 | 目录按遗址、形制、时代分面；实测北魏，URL/已选范围/目录同步。 | 三个洞窟的时代和关键词 AND 筛选；可删除标签、结果计数和零结果恢复是本地教学扩充。 |
| 查看壁画 | 深色独立查看器；Zoom in 与 Zoom out 放缩已实测。 | 原生 dialog、100%—300%有限缩放、复位和视域滚动；不用鼠标拖拽冒充原站完整引擎。 |
| 放大/回看 | 源端高清图像可以进入局部和返回全貌。 | 仅 **562×253** 官方公开预览。放大不增加实际精度，保留水印并链接原站高清。 |
| 关闭 | 原站查看器是独立页面。 | 本地关闭/Escape 返回触发按钮，为局部教学选择。 |
| 手机与减少动态 | 原站触屏、键盘与全部分面组合未完整核验。 | 本地目录单列，二维滚动仅在图像視域；手动状态保留，无自动运动。 |

浅色目录和深色影像区域固定，未加独立声音。字型、间距、操作色为本地拟合；高清分块服务、账户、订阅与完整数据库不复制。原始公开图像的字节、尺寸、来源、水印、权利和 hash 见[素材清单](assets-manifest.json)。

本地在 1440px 桌面和 390px 手机实际浏览器验收：素材可加载、无整页横向溢出；组合条件的空状态、清除复位、查看器缩放、Escape 与焦点归还通过。桌面与手机标准预览来自实际浏览器。公共素材映射、回退和缓存不阻断静态首图。
