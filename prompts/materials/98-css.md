# 98.css · 复古桌面组件 · 复用 Prompt

[结构化条目](../../entries/materials/98-css.json)

使用固定版本 98.css 0.1.21，为当前任务构建一个有实际用途的复古设置窗口、素材目录或进度界面。使用原库 window、title-bar、status-bar、sunken-panel、table 和 progress-indicator 样式，行为由小量原生 JavaScript 实现。所有控件保留语义与可访问名称，标签键盘方向导航，最终文本至少 12px，扩大触控区域，窄屏自然重排，不缩小整个界面。真实任务连接真实进度；若使用教学模拟须明确标注，允许暂停、重置、手动前进，后台与减少动态时停下持续变化。保存 MIT CSS 与 CC BY-SA 3.0 字体的独立署名许可，自托管所需文件，提供静态后备。

## 制作约束

- 固定 98.css 0.1.21；原库仅有 CSS，本地 JavaScript 实现行为。
- 原库控件 11px 已在适配层提高为 14px，辅助信息不低于 12px；不以缩放还原旧屏幕。
- CSS 为 MIT；随包 MS Sans Serif 与 Bold 字体来自 lou，采用 CC BY-SA 3.0，需保留独立署名与许可。
- 模拟进度每 240ms 增加 2% 为本地参数，不产生文件；真实任务必须接真实进度。
- 页面隐藏或切换演示暂停，返回需用户继续；减少动态时手动步进。
- 静态后备保留样式和说明；没有 JavaScript 时应用、筛选和演示计时不执行。
