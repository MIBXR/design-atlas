# 文字目录行内浮现摄影预览 · 复用 Prompt

[结构化条目](../../entries/patterns/inline-row-photo-preview.json)

为【作品目录】实现「文字目录行内浮现摄影预览」。保留编号、标题和辅助信息的稳定列线，将 180px × 120px 的照片定位在当前行右侧 220px、垂直居中。指针进入时让照片透明度从 0 到 1、比例从 0.94 到 1，标题右移 8px、箭头右移 6px；离开后还原。透明度与箭头过渡 0.5 秒，预览与标题位移过渡 0.6 秒，使用 cubic-bezier(0.22, 1, 0.36, 1)。来源在 1100px 及以下隐藏预览，未实现键盘等价预览，作品链接仍为占位；实施时用 :focus-visible 给出同样的预览，并连接真实详情，不能只靠图片传达关键内容。减少动态时取消位移和缩放并即时显隐，同一行不叠加随指针预览。

## 制作约束

- 来源在 1100px 及以下隐藏摄影预览；窄屏目录继续显示文字。
- 来源没有 :focus 或 :focus-visible 等价预览，键盘策略是实施建议。
- 来源作品链接使用 # 占位，未实现真实系列详情；迁移时提供真实目的地。
- 预览不接收指针事件，不遮挡该行文字与操作；换用有权使用的照片后重新检查裁切和行间遮挡。
