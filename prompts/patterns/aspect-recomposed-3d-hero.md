# 三维主角随画幅重新构图 · 复用 Prompt

[结构化条目](../../entries/patterns/aspect-recomposed-3d-hero.json)

为【目标首屏】实现「三维主角随画幅重新构图」。首次布局与容器尺寸改变时读取容器宽高比，以五档位置与等比缩放调整同一三维主角：大于 1.9、大于 1.4、大于 1.0、大于 0.7 及其余画幅分别使用来源参数作为构图参考，并根据目标模型与相机校准。横屏将主角安排在右侧，竖屏缩小并上移，为左下标题与行动留白；大气层与主角同步变换。标题、说明和行动保留为语义内容，装饰画布不进入键盘焦点顺序。减少动态时保留响应式构图，停止旋转与着色器时间推进并提供暂停控制；来源没有实现完整静止和用户暂停，这些是实施建议。可见性机制另行管理渲染生命周期。

## 制作约束

- 阈值依据首屏容器宽高比，不是视口宽度；位置值是三维场景坐标，缩放相对来源模型，迁移时需按目标模型与相机重新核对。
- 星球与大气层必须同步重新构图，标题和操作控件保持独立的语义内容层。
- 来源未实现用户暂停；减少动态时跳过对象旋转，但仍更新着色器时间并渲染，不能将其描述为完整静态模式。
