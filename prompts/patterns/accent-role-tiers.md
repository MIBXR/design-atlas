# 主题色分层：五个配色角色 · 复用 Prompt

[结构化条目](../../entries/patterns/accent-role-tiers.json)

把品牌主题分成深色强调 --accent-1、强调文字 --accent-2、实心底 --accent-3、高亮条 --accent-mark、柔和底 --accent-4 五个角色。实心字使用 --accent-3-ink。链接与焦点用 -1，眉题和侧栏当前项文字用 -2，顶栏当前页和复制 Prompt 用 -3，高亮条与按钮底分别赋值，侧栏状态用 -4。为品牌与深浅主题定义完整变量组，切换只更新根选择器；标志、装饰与作品图版独立配色。数值从来源 style.css 取用，研究原件的对比度见 docs；当前状态同时有文字、字重或 aria-current，减少动态时直接切换。

## 制作约束

- 五个角色分别用于深色强调、强调文字、实心底、高亮条和柔和底；实心字与实心底成对使用。
- 沿用来源各主题实际值，品牌图形和作品图版保留独立配色。
