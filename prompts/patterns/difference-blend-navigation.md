# 跨深浅背景的差值导航 · 复用 Prompt

[结构化条目](../../entries/patterns/difference-blend-navigation.json)

为【目标页面】实现「跨深浅背景的差值导航」。将固定顶栏的文字与标记设为暖纸色 #f2efe8，并对该层使用 mix-blend-mode: difference，使导航经过摄影、纸色正文和墨色章节时按下方像素合成。导航只承担章节入口，正文对比另行处理。差值混合不能保证所有图片上的对比度，需要实测；检查每张图、深浅表面及新增合成层。来源只有悬停下划线，实施时保留原生链接并用 :focus-visible 提供清晰的焦点反馈。减少动态时直接显示顶栏。若同一层还采用语义主题色切换，重新验证混合结果，不直接套用原色对比结论。

## 制作约束

- 差值混合不能保证所有图片上的对比度，需要实测。
- 混合依赖导航下方的实际像素与合成层级，新增背景、遮罩或隔离层后需重新核对。
- 来源导航只有悬停下划线，未实现与其等价的键盘焦点下划线；键盘策略是实施建议。
- 迁移时使用有权使用的摄影与真实章节，并按目标页面重新验证颜色。
